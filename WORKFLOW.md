# Production workflow

The user authorized autonomous creation of the complete supplied NPTEL playlist
and publication to a new GitHub repository. This is an independent study edition,
not an official NPTEL transcript or an endorsed textbook.

  workflow, original HTML chapter, source separation and verification dimensions.

The reference projects' validation is not evidence for this project. Their

independent reviewer identities are inferred from the reference workflow.

## Process

1. Inventory the exact playlist; acquire metadata and captions privately.
2. Read caption text in lecture order; map substantive topics to chapter sections.
   Preserve real time locators and explicit modality limitations.
3. Specify assumptions, notation, dependencies and main statements before writing.
4. Author original HTML sections with definitions, proofs, counterexamples,
   worked examples and exercises with full solutions. Distinguish lecture spine,
   standard external results, and original teaching constructions.
5. Calibrate a complete initial chapter against the inspected exemplars.
6. Conduct mathematical and teaching editorial passes with the science-editor
   standard. Obtain two full independent reviews per chapter from agents other
   than its author. Retain actual reports and hashes; verify repairs and freeze
   manuscript bytes with LF line endings before final acceptance.
7. Verify executable algebra examples, math rendering, navigation, links,
   desktop/mobile layout, local rebuild and publication inputs.
8. Exclude raw captions, media, private paths, metadata URLs with signatures,
   credentials and unrelated inputs. Commit original notes and public provenance.
9. Create a new repository, push, and verify remote commit and published reader.

## Skills applied

transcript-grounded-textbook, analyze-sources, rigorous-explainer, science-editor.
The transcript-grounded workflow permits autonomous continuation without a
user-requested review gate. The requested deliverable is lecture notes, not a
commercial book or a coauthored research monograph.
